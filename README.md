### 📌 Featured Project

#### 🏫 [School Office](https://www.schooloffice.tech) — School Management ERP
A single dashboard replacing registers, spreadsheets and separate apps for school administration. Live and used by schools across Rajasthan.

- **11 integrated modules** — Admissions, Attendance, Timetables, Fees, Online Exams (CBT), Paper Generator, Staff HR & Payroll, E-Learning/LMS, Communication Hub, Homework, Transport, Analytics
- **One record, everywhere** — attendance flows into fees and alerts, exam results roll straight into report cards, no manual re-entry
- **Role-based logins** — teachers, accountants and principals each see only what's relevant to them
- Registered as a **Micro (MSME) enterprise**, founded 2025 in Ajmer, Rajasthan

**Backend repo:** [SCHOOL-ERP-backend](https://github.com/Muniramm890/SCHOOL-ERP-backend) — Node.js backend with WhatsApp API integration for parent communication.
